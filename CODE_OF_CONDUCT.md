# Code of Conduct

Be kind, be respectful, be helpful.

## Rules

**Do:**
- Use welcoming language
- Respect different views and experiences
- Accept feedback gracefully
- Focus on what's best for the project
- Show empathy to others

**Don't:**
- Use sexualized language or images
- Insult, troll, or attack others
- Harass anyone publicly or privately
- Share others' private info without permission
- Disrespect Islamic values
- Spam or self-promote

## Enforcement

Report issues by creating a GitHub issue with label "Code of Conduct".

We'll investigate within 48 hours. Consequences for breaking these rules:

1. **Correction** — private warning
2. **Warning** — limited interaction for a set time
3. **Temporary ban** — no interaction with the community
4. **Permanent ban** — removed from the project
